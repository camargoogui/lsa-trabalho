# P12 - Matriz de acesso 8 usuários x diretórios

**Responsável:** Guilherme Paes Camargo (RM576842)

A matriz cobre os 8 usuários (6 colaboradores e 2 contas de serviço) em 23 diretórios, indicando para cada célula se o usuário entra (E), lista (L), lê um arquivo de referência (R), cria (C) e apaga (A). Ela foi escrita a partir das regras do enunciado aplicando o menor privilégio onde nada foi dito, e é o contrato que o `testes.sh` (P13) verifica teste por teste. A matriz foi gerada pelo próprio `testes.sh --matriz`, então os dois nunca ficam diferentes.

Arquivo: `matriz.md`.
